# Charte graphique KayArt

Date : 14 juillet 2026

Source : export Sigma/Figma Make `Implement Features.zip`.

## Direction retenue

- Ambiance atelier nautique premium.
- Fond ivoire clair au lieu d'un theme sombre/neon.
- Bleu profond pour l'identite et les zones fortes.
- Accent cuivre pour les actions et les reperes.
- Cartes blanches, bordures fines, rayons discrets.
- Typographie editoriale pour les grands titres.
- Photographies nautiques/atelier comme signal visuel principal.

## Tokens appliques

- Ivoire : `#f6f3ee`
- Texte : `#1a1c1e`
- Bleu profond : `#1d3a4a`
- Bleu eau : `#5b8fa8`
- Cuivre : `#b5652a`
- Vert doux : `#8caf7e`
- Or discret : `#d4a853`

## Application actuelle

- Page d'accueil : hero photo plein cadre, H1 `KayArt`, texte atelier.
- Cartes produits : visuels photographiques selon neuf/occasion/service.
- Sections : contraste clair + bande bleu profond.
- Admin : formulaires et tableaux remis sur fond clair, dans un style plus calme.
- Boutons : cuivre pour l'action principale, bleu profond pour les actions secondaires.
