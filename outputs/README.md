# Archives et preuves

Les dossiers datés conservent des rapports et résultats historiques. Ils ne remplacent pas [l’état V1 actuel](../docs/v1-status.md) ni [les guides actifs](../docs/README.md). Les anciens nombres de tests et constats de configuration valent pour la version et l’environnement observés à leur date.

Le lot le plus récent est [la stabilisation du 13 septembre](stabilisation-2026-09-13/README.md). Les preuves réutilisables restent liées depuis leurs guides ; elles ne sont pas déplacées pour préserver ces références.

Les prochains résultats temporaires vont dans `latest-verification/`, ignoré par Git. Les profils de navigateur, builds copiés et caches vont dans `work/`. Ne pas stocker de secrets, de fichiers d’environnement ou de données clients dans les preuves.
